# Supermarket Management System

A Python-based supermarket management application developed as a school project.  
The system supports handling orders, managing daily sales, and generating reports in a simple and intuitive way.

---

## 📋 Features

- Manage product orders: add, update, delete orders  
- Maintain a **Daily Sales** summary view derived from the orders table  
- Generate sales graphs and reports using `matplotlib`  
- Easy setup using `mysql-connector` for the MySQL backend  
- Clean console/GUI (depending on implementation) interface  
- Modular source structure (found under `src/`)

---

## 🧰 Tech Stack

- **Language**: Python  
- **Database**: MySQL (via `mysql-connector-python`)  
- **Visualization**: `matplotlib`  
- **Dependencies**: See `requirements.txt`
